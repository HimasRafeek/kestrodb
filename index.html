KestroDB benchmark tracker

KestroDB against other embedded databases on the same machine, with the same JSON documents and matched durability: every acknowledged write was flushed to disk. Higher is better everywhere.

Record a new run: node bench/compare.mjs --runs 3 --record "what changed", then reload this page. Install the other databases once with cd bench/competitors && npm install.

Data: results/bench-history.json. Each value is the median of the run's repetitions. Results describe this machine only; run the benchmark on your own hardware before relying on them.
